# iCUE Memory Guard v0.1.0

**Published experimental prerelease · Windows 11 x64 · JZB Apps**

A local patch for identified allocation-ownership paths in Corsair's CPU identification service and its bundled CPUID SDK. Setup derives the modified files from the user's installed originals, verifies both output hashes, and keeps protected originals for recovery. Original and modified Corsair/CPUID images are not distributed.

## Exact compatibility

The tested files identify themselves as **CorsairCpuIdService.exe 5.52.93.0** and **cpuidsdk64.dll 1.3.4.7**, on Windows 11 Pro x64 build 26300. Both files must match the exact original/patched SHA-256 contract in the [release validation record](https://github.com/jb14813/iCUE-Memory-Guard/blob/v0.1.0/VALIDATION.md). Labels alone do not establish compatibility; even small vendor changes can invalidate the patch.

## Installation, updates and recovery

Download and verify [iCUEMemoryGuard-Setup-0.1.0.exe](https://github.com/jb14813/iCUE-Memory-Guard/releases/download/v0.1.0/iCUEMemoryGuard-Setup-0.1.0.exe), then run it as administrator. Windows' built-in PowerShell 5.1 is used; no separate runtime/framework, driver or dependency download is required. Applying/restoring the patch reloads only CorsairCpuIdService, so sensor readings can pause briefly.

No resident guard process, service, scheduled task or tray icon is added. Status and Check are read-only. An iCUE update can overwrite the fix; there is no automatic reapplication to unfamiliar files. Unknown vendor files are preserved.

Restore returns owned exact patched files to the verified originals. Use Windows Installed apps to uninstall the guard application as well. Unsafe mixed or changed files can stop restoration/uninstall; verified recovery material is retained. Do not replace newer vendor files with an older patch or delete backups to bypass a conflict.

## Signing and validation limits

Modified vendor images lose their valid vendor signatures. Windows application-control policies may block them, and instability, sensor-function loss or update conflicts are possible. The tool does not change certificate trust or stored Windows execution policy.

The installer and generated uninstaller use the retained JZB Apps **self-signed** identity, so an unknown-publisher/SmartScreen warning remains possible. [Verification instructions](../../SIGNING.md), [SHA256SUMS](https://github.com/jb14813/iCUE-Memory-Guard/releases/download/v0.1.0/SHA256SUMS), its detached signature, public certificate and verifier scripts are on GitHub. Installer SHA-256:

    019ee74ec7d1e9912d5c85d7619ebfb756b7ff7a38d4485fb390adcef0aeb51b

Finite local coverage includes an approximately eight-minute heap trace with stable sampled BSTR counts, CPU temperature/load and fan-response checks, exact output equivalence, real install/uninstall/restore/reinstall without reboot, and failure/recovery/integrity tests. This does not establish that every leak, system, game or future iCUE build is supported. GitHub Actions builds **unsigned development artifacts**; the signed prerelease installer is the normal download.

## Privacy, license and support

Patch checks and recovery data stay local; the guard has no automatic diagnostic-upload feature. Review reports before manually sharing them. Corsair/iCUE privacy settings are outside this tool's scope.
